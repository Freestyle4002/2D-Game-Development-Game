# 🚀 Space Escape - 2D Game

A fast-paced console-based space shooter game where you pilot a ship through an asteroid field and dodge incoming threats while trying to survive as long as possible.

## About the Game

**Space Escape** is a retro-style 2D arcade game built in C#. Navigate your spaceship through a field of asteroids and comets while avoiding collisions. The game features progressive difficulty levels, scoring mechanics, and increasingly challenging hazards that test your reflexes and dodging skills.

## Features

- **Dynamic Starfield Background** - Beautiful twinkling stars that create a sense of movement and depth
- **Progressive Difficulty** - Each level increases the spawn rate and speed of hazards, making the game more challenging
- **Two Types of Hazards** - Asteroids (red) and Comets (yellow) with different movement patterns
- **Lives System** - Start with 3 lives; lose them by colliding with hazards
- **Score Tracking** - Earn points as you survive; reach score milestones to level up
- **Smooth Controls** - Responsive up/down arrow key controls for intuitive movement
- **Main Menu** - Start, quit, and restart options from a clean menu interface
- **Game Over Screen** - Shows final score with restart and return-to-menu options

## How to Play

- **Up/Down Arrows** - Move your ship up or down
- **Q** - Return to main menu during gameplay
- **R** - Restart after game over
- **M** - Return to menu after game over
- **1** - Start game from main menu
- **2** - Quit from main menu

## Gameplay Mechanics

- Navigate the `60x20` play area to avoid incoming hazards
- Comets move chaotically in multiple directions; asteroids move more predictably
- Each collision costs one life
- Score increases automatically as you survive
- Advance levels when reaching score thresholds
- Game speed increases with each level for added challenge
